# floriculture-ai

AI-powered floriculture platform for plant identification, disease detection, export quality assessment, and forecasting.

## Setup

Requires Python 3.11.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Run the test suite with:

```powershell
python -m pytest
```
